> **Grow** es una aplicación web interactiva de vanguardia diseñada para demostrar micro-interacciones lúdicas, animaciones basadas en física y retroalimentación táctil visual. Construida sobre la versión más reciente de **React 19** y **GSAP 3.15**, explora la frontera del diseño de interfaces modernas y atractivas.

---

## 🌟 Características Principales

* **Stack de Última Generación (React 19 + GSAP React):**
  * Implementación directa de las APIs contemporáneas de React 19 combinadas con `@gsap/react` para un ciclo de vida limpio de animaciones.
* **Efectos Cinemáticos & Feedback Visual:**
  * Uso de *Canvas Confetti* y transiciones elásticas que celebran la consecución de objetivos e interacciones del usuario.
  * Iconografía vectorial moderna y limpia con **Lucide React**.
* **Arquitectura Liviana y Modular:**
  * Componentización atómica que permite reutilizar botones interactivos, tarjetas de crecimiento y barras de progreso fluidas.

